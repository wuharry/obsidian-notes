## 一、閱讀方式與狀態定義

- **① 結論／根本原因：** 找到程式、完成部署、玩家實際驗收是三件不同的事，本文件分開記錄。
- **② 怎麼解：** 每項狀態附目前來源；原設計與現況不一致時列為差異，不直接改回原案。

| 狀態 | 意義 |
| --- | --- |
| **已實作** | 已找到可用程式、資源及入口；不代表本次已重新試玩 |
| **部分實作** | 已完成指定卡牌或部分流程，尚未涵蓋原案全部要求 |
| **未實作** | 在本次核對範圍未找到完整功能及入口 |
| **待驗收** | 已有程式或歷史測試，但缺指定版本的實機／正式服務／真人證據 |
| **待決策／延後** | 原案與現行規則不同，或已有延後決議；不自動列為必須補做 |
| **歷史已部署** | 有指定版本的部署紀錄；不代表目前工作樹的新版也已上線 |
| **來源分支** | 已在功能分支提交並推到 GitHub，尚未合併 `main`，也沒有打包發布 |

- **③ 為什麼這樣解：** repo 的部分總覽仍保留舊版數字；以現行規格、實際程式／資源及有版本的驗收文件交叉核對，避免沿用過時待辦。
- **④ 舉例：** R17 正式服已是 protocol 28，但只有 macOS 成品通過驗收，所以不能寫成「Windows／Linux R17 已發布」。

## 二、目前遊戲定位

- **① 結論／根本原因：** 本作是《紙鴉牌 / Deckmarch》的可玩原型：有收藏、自組牌、三種 PvP、天梯，以及 30 層 PvE 試煉之塔；正式服已上線，但多數平台的新玩家包仍在熱修。
- **② 怎麼解：** 保留「站位、魔力回收、從者／法術與反制」核心；玩家用持有卡自組牌，AI 使用內部主題預組；正式獎勵（金幣、段位、爬塔首通）一律由專服與資料庫結算。
- **③ 為什麼這樣解：** 四路前後排、條件連動與派系效果已能構成準備和兌現；剩餘工作應分成玩法擴充、正式服務驗收與品質（可讀性、平衡、手機）調整，不再把已有功能重做一次。
- **④ 舉例：** 新玩家可先做引導練習、領起始牌組或抽新手卡，選用合法牌組挑戰 AI 或爬塔；外網正式入場由帳號服務驗證雲端持卡。引擎為 Godot 4.7.2：專案預設 Forward+，Windows 預設 Compatibility＋ANGLE，Android 使用 Mobile 渲染器（APK manifest `org.godotengine.rendering.method=mobile`），macOS 走 Metal（R17 修正 RGB8 貼圖在 Metal 上的執行期轉換）。

## 四、現行規則摘要

### 1. 對局、站位與行動

- **① 結論／根本原因：** 現行是四路、自然十魔力與卡面決定的行動選擇；10-16 起加入起手換牌、回收改向上取整，10-19 起要抽牌時牌庫已空即判負。
- **② 怎麼解：** 以現行 `BoardLayout`、`BattleManager`、`opening_mulligan.gd` 與卡面核對下表。

| 項目 | 現行實作 |
| --- | --- |
| 玩家生命與勝負 | 起始 20（`hero.gd` `max_hp`）；對手生命歸零、對手投降，或對手要抽牌時牌庫已空，即獲勝 |
| 棋盤 | 每方四路 × 前後兩排，共八格；全場十六格。鍊金鍋爐放在獨立支援區，不佔卡槽、不參與戰鬥 |
| 普通攻擊目標 | 可跨路指定敵方前排；敵方後排同欄有活前排時受保護。嘲諷等明文限制另算 |
| 直擊英雄 | 檢查攻擊者同路敵方前排及嘲諷；飛行依明文特例，不能穿透後排保護 |
| 自然魔力 | 起始上限零；自己回合開始加一並回滿，上限十 |
| 回收手牌 | 得到 `ceil(Cost / 2)` 暫時魔力（`recycle_mana()`，10-16 起向上取整）；可超過自然上限，自己下回合清除；用後下一自己回合不能再回收 |
| 起手與先後手 | 主持端隨機決定先手，與房主及網路座位分開；雙方起手五張後各可換零至五張一次，換出的牌洗回牌庫，不算抽牌、棄牌或回收；雙方確認才開局。先手開局不另抽，後手首次行動前照常自然抽一張 |
| 後手後援 | 每局一次，後手可在自己的回合按「後援」獲得一點暫時魔力；可保留稍後使用，與回收併用、不算卡牌或施法，下次自己回合開始清除 |
| 自然抽牌／手牌 | 回合開始效果結算後、自然抽牌前空手就抽兩張，否則一張；法術／戰吼照卡面。手牌上限八，溢出入墓；要抽牌時牌庫已空即判負（`draw_cards()`），沒有疲勞傷害 |
| 普攻／技能 | 普攻每回合一次；強化攻擊及標示共同行動的支援與普攻擇一，獨立攻擊保留額外攻擊；一般支援可另用 |
| 召喚暈眩 | 普攻與兩種攻擊型技能當回合不能用，衝鋒例外；非攻擊技能可用 |
| 戰鬥 | 普攻／強化攻擊打從者會受到反擊；獨立攻擊不受反擊；打英雄不受反擊 |
| 靈裝／伏印 | 新裝替換舊裝並收回加成；伏印不佔槽，多數埋於己方宿主，屍變伏印另有敵方宿主規則 |
| 結界 | 每方最多一張，新結界替換自己的舊結界；不是全場共用一張 |
| 思考時間 | PvE 不限時；PvP 每回合一百秒（`LIMIT_MS := 100000`），最後十五秒倒數（`WARNING_SECONDS := 15`）；逾時後完成當前結算再換邊。起手換牌另有 30 秒期限，兩人確認後才開始回合時鐘 |
| 投降 | 正式對戰可確認投降，由權威端判定對手獲勝；不扣英雄生命、不播假死亡 |
| 回合階段 | 有回合開始／抽牌／結束處理與反制窗口；沒有玩家獨立切換 Main／Attack 階段的完整控制介面 |

- **③ 為什麼這樣解：** 同時分清一般規則與卡牌例外，才不會把角色技能、沙盒或派系操作當成所有牌共有能力。
- **④ 舉例：** 劍士選免費三傷普攻，或一魔力連擊兩次各二傷；牧師治療後仍可普攻。回收一費卡現在也能得一點暫時魔力（舊規則是零點）；自然魔力十時，十一費卡至少回收一張二費卡即可支付。

- **② 怎麼解：** 按 `CardData.card_type` 與 `is_token` 統計，不把衍生物當作可抽正式卡；本次直接數 `data/cards/` 頂層與 `data/cards/tokens/`。

| 靈裝 EQUIP | 9 | 0 |
| 秘術 ARCANA | 67 | 11 |

| 配套資料 | 現況 |
| --- | --- |
| AI 參考預組 | 十九套（`Deck.PRESET_IDS`），每套二十種、各三張；不代表玩家免費持有 |
| 卡包定義 | 二十六份（`data/packs/`）；商店販售旅者基礎包與九個 `theme_*` 主題包，其餘是新手與舊測試包 |

| 稀有度 | 普通／稀有／史詩／傳說；現行金屬卡框與原案銀金紫配色不同 |

- **③ 為什麼這樣解：** 卡種數、持有張數及預組張數不同；部族標籤也不等同英雄職業選擇。
- **④ 舉例：** 鍊金材料與藥劑有卡片資源及圖鑑內容，但屬衍生牌，由卡牌效果產生，不直接混入一般抽池。完整卡表見[可搜尋卡牌總表](../../repo/card-game-demo-4.5--main/docs/card-catalog.html)。

### 3. 收藏到對局的現行流程

- **① 結論／根本原因：** 已有新手抽卡、每日券、金幣主題包與起始牌組四種取得方式；奪牌新局暫停，爬塔首通是另一條由專服發卡的路。
- **② 怎麼解：** 訪客本機與登入帳號分開處理；金幣、段位與首通只由專服／資料庫結算，客戶端只顯示收據。

```mermaid
flowchart LR
    Identity[訪客或登入帳號] --> Cards[新手抽卡／每日券／金幣主題包／起始牌組]
    Cards --> Collection[保存持有卡]
    Collection --> Deck[自組並選用合法牌組]
    Deck --> AI[單人 AI，可中斷續玩]
    Deck --> LAN[區網房主主持]
    Deck --> Auth[正式外網：帳號持卡入場驗證]
    Auth --> Lobby[輕鬆／天梯／奪牌新局暫停]
    Auth --> Tower[試煉之塔：專服＋權威 AI]
    Lobby --> Battle[雙方準備、專服對戰]
    Battle --> Results[戰績、金幣、段位]
    Tower --> FirstClear[每層首勝送一張卡]
    Results --> Collection
    FirstClear --> Collection
```

| 流程 | 現行規則與限制 |
| --- | --- |
| 新手 | 新訪客／新政策帳號零卡起始，贈送一百五十張單卡抽取額度；批次可選一／十／五十／一百張，剩額可稍後領取 |
| 提早組牌 | 合法持有六十張即可選用進場，不必抽完全部新手額度 |
| 每日 | 每個登入日一張包券，台北日期換日，未花券累積；未登入日不補發 |
| 一般包 | 每包五張、消耗一券；批次可選一／十／五十／一百包；新手剩額歸零才開放一般包 |
| 抽取權重 | 普通／稀有／史詩／傳說 61%／30%／7.2%／1.8%；同級等機率，持有三張者排除。每包第 5 張至少稀有：普通的權重併入稀有，史詩與傳說不變；新手抽每 5 抽的第 5 抽同樣保證。沒有累積保底 |
| 金幣主題包 | 100 金幣立即抽五張入收藏；扣金幣與開包在同一交易，失敗不扣金幣、不發部分卡 |
| 金幣與每週 | 合格正常勝 +40、敗或平 +20（專服確認正常完賽、至少 60 秒且 4 回合；每日 20 場、同對手每日 3 場）；每週 5 局領 1 包券、10 局領 2 包券、20 局領自選一張正式卡的資格 |
| 帳號保存 | 登入帳號的持卡、額度、包券、金幣、收據及正式入場由 SQL 決定；訪客收藏與本機牌組存檔不能作為雲端持有權證明 |
| 奪牌 | 每局雙方重新同意，已開賽後判負失去一張牌；2026-10-21 起伺服器拒絕新奪牌局，舊戰利品、收據與重送保留。重開前要先有 PvP 斷線重連，並處理分身帳號用爬塔卡轉給主帳號的問題 |
| 爬塔首通 | 每帳號每層一張，重送／重打不多發，不給段位、金幣或奪牌；第 1 層 70／20／8／2%，第 30 層 41／20／25.4／13.6%；該稀有度已無可收副本時保留待領資格 |

- **③ 為什麼這樣解：** 舊 R2 的本機每日免費包及 R3／R4「抽完才進場」是版本歷史，不再直接套用目前工作樹。
- **④ 舉例：** 玩家打完一場合格的天梯勝局得 40 金幣，再花 100 金幣可買一個主題包；爬塔第 1 層首勝送一張卡，之後重打只算練習。

## 八、原 v2.0 完整企劃案（設計保留區）

> 以下保留原始設計細節，供追溯與後續取捨；包含已改規則、未實作功能及美術目標。**目前進度與規則以上方表格為準**，不是以下每一條都已落地。原稿更新日期為 2026-04-21。

## 1. 核心玩法規則 (Core Mechanics)

### 1.1 基礎規則

- **勝利條件**：將對手主堡（玩家）生命值從 **20** 降至 **0**。
- **玩家生命值**：20 點。
- **戰場佈局**：雙方各 **5** 條並排格子（**路線 / Lane**）。
	- 每條路線可容納：**前排從者**（可被攻擊/阻擋）與其**附著的靈裝 / 伏印**（若有）。
- **攻擊規則**：
	- 若該路線前排**沒有敵方從者阻擋**，則直接攻擊對方玩家（Face）。
	- 若有阻擋，則先對該從者造成傷害。

### 1.2 資源機制（魔力 Mana）

- 遊戲開始時 **魔力上限 = 0**。
- 每位玩家在**自己回合開始時**：
	- **魔力上限 +1**（最高 10）
	- **魔力回滿至上限**
- **未使用的魔力不會累積**到下回合。
- 每回合開始時可以選擇捨棄一張牌,根據他的消耗魔力的數一半(小)回流給這回合的魔力counter(也可以不捨棄)

### 1.3 召喚機制 (Summoning Logic)

- **一般召喚**：支付卡牌右上角標示的 **Cost**（魔力）。
- **獻祭召喚 (Sacrifice Summon)**：
	- **觸發時機**：當現有魔力 < 目標卡牌魔力時，可選定場上一張卡牌進行獻祭以補足差額。
	- **計算公式**：`獻祭單位消耗魔力 + 當前剩餘魔力 = 召喚卡牌魔力`
	- **被獻祭單位的條件（需同時滿足）**：
		1. 本回合尚未承受過攻擊
		2. 本回合尚未進行攻擊
		3. 本回合尚未發動主動效果
		4. 生命值 > 50%（計算：`Math.floor(MaxHP / 2)`）
- **捨棄召喚 (Discard Summon)**：
	- **條件**：需捨棄手牌才能召喚（無視魔力或減少魔力，視單卡設計）。
	- **代價類型**：捨棄任意一張手牌 / 捨棄特定類型（如魔法卡）。
	- 獲得捨棄的卡牌的消耗點數的一半魔力

## 2. 回合階段與流程 (Turn Structure)

> 目標：建立清晰的「階段次序」與互動窗口（含 Stack）。可參考 MTG 的回合結構概念，但以本遊戲規則為主。

1. **開始階段（恢復階段）**
	- 魔力上限 +1、魔力回滿
	- 進行清算：解鎖從者、解除持續狀態等
	- 「回合開始時」觸發效果進入堆疊（若使用 Stack）
2. **抽牌階段**
    
	- 抽 1 張牌（牌庫用盡時的規則另行定義）
    
	-（可選）檢查手牌上限並丟棄多餘手牌
    
3. **主要階段 (Main Phase)**
	- 可使用手牌：召喚從者、施放秘術、佈置伏印、附著靈裝、啟動主動能力等
	- 玩家可自行決定進入攻擊階段的時機
4. **攻擊階段**
	- 宣告攻擊者與攻擊目標（路線/前排阻擋規則）
	- 於宣告、傷害計算前後，皆存在反應窗口（瞬咒/伏印觸發等）
5. **結束階段**
	- 回合結束檢查、處理回合末效果
	- 檢查敗亡條件（生命值 ≤ 0 判定勝負）

### 2.1 堆疊系統（Stack）

- 所有「施放的秘術 / 瞬咒」、「伏印觸發效果」、「可回應的能力」會進入堆疊。
- **結算順序：後進先出（LIFO）**：最後加入堆疊的效果最先解決。
- 雙方可在適當窗口互相回應，形成策略深度（預判、誘導、反制）。

## 3. 卡牌系統與邏輯 (Card System)

### 3.1 從者卡 (Unit / Followers)

- **定義**：場上實體單位，可攻擊、防禦、承受傷害，可搭載靈裝、被附伏印卡。
- **數值結構**：
	- `Cost`（藍 / 右上）：召喚所需魔力
	- `Sacrifice`（黃 / 左上）：獻祭可提供的魔力值
	- `Atk`（紅 / 左下）：攻擊力
	- `HP`（綠 / 右下）：生命值
- **技能觸發類型**：
	- **進場發動 (On Play)**：打出/召喚成功時立即生效
	- **位置觸發 (Lane Effect)**：依前排/後排、同路線單位等條件生效
	- **主動發動 (Active)**：玩家手動啟動，通常消耗資源
	- **反應觸發 (Reactive)**：如「受到攻擊時 / 受到傷害時 / 受到效果影響時」

### 3.2 靈裝卡 (Armament / Relic)

- **定義**：附著於從者上的裝備/聖物，提供持續加成或特殊能力。
- **基本規則**
	- 使用時需支付魔力，並指定 1 名從者作為宿主
	- 宿主陣亡或效果解除時，靈裝通常離場（除非卡牌另有敘述）
- **常見效果示例**
	- 「靈裝：附著後，此從者攻擊力 +X」
	- 「靈裝：此從者獲得嘲諷（Taunt）」
	- 「靈裝：此從者每次攻擊額外造成 1 點傷害」

### 3.3 魔法/秘術卡 (Spell Cards)

- **一般秘術**：主動消耗魔力施放，進入堆疊後結算，結算後離場。
- ==**反制秘術 (Counter)**：==
	- **觸發條件**：敵方發動秘術/瞬咒後（依卡牌文字）
	- **消耗**：依卡牌設定（同秘術）

### 3.4 瞬咒卡 (Flash / Reaction Spells)

- **定義**：可在對手回合或我方回合施放的反應型法術（類似 Instant）。
- **用途**：反制、打斷、保護、瞬間增益/傷害。
- **結算**：與秘術一致，進堆疊並遵循 LIFO。

### 3.5 伏印卡 (Trap / Sigil)

- **機制**：埋伏於我方某張從者卡牌後底下（Sub-layer），不立即生效。
- **消耗**：通常在埋設時支付（或免費），觸發時不再消耗。
- **觸發條件（示例）**
	- 宿主成為攻擊目標時
	- 宿主受到效果影響時
- **預設**：觸發後銷毀（若要多次觸發，需在卡面文字定義）。

### 3.6 領域卡 (Domain / Field Card)

- **定義**：影響整個戰場環境的持續性卡牌。
- **基本規則**：同時間只存在 1 張；新領域覆蓋舊領域。
- **結算建議**：可設計為「使用後立即生效並常駐」，是否進堆疊視規則統一。

## 6. 玩法延伸構想（保留區）

### 6.1 《貪婪之島》致敬機制 (Greed Island Inspired)

一套獨立的「咒語卡 (Spell Card)」系統，用於非戰鬥或戰鬥輔助：

- **同行 (Companion)**：傳送 (Teleport)
- **磁力 (Magnet)**：躍遷 (Warp)
- **盜竊 (Steal)**：通用搶奪
- **格擋 (Block)**：防禦性技能
- **黏手指 (Sticky Fingers)**：交換雙方的「獨特口袋」卡牌

### 6.2 遊戲模式與經濟 (Game Modes & Economy)

- **口袋系統 (Pocket System)**
	- 共通口袋：基礎卡池
	- 獨特口袋：特殊/稀有卡池
	- 稀有度：白 < 藍 < 黃（金）< 紫
- **活動場景**
	- 拍賣會：持有 10 張卡片可進入
	- 自由賭場：持有 30 張卡片可進入
- **對戰模式**
	- 天梯競技場 (Ranked)
	- 自由對戰（不賭上卡牌）

### 6.3 場景提案：無名者暗巷 (The Nameless Alley)（草案）

- **核心規則：強制匿名 (The Masquerade)**
	- 進入時強制裝備「灰色斗篷」
	- ID 隱藏，頭頂顯示「??? / 流浪者」
	- 無法打字/發話，只能使用簡單表情符號
- **地圖結構：動態迷宮 (The Maze)**
	- 俯視角 HD-2D（探索）→ 進戰鬥切回橫向
	- 迷霧 (Fog of War) + 隨機障礙（Roguelite）
	- 分流房間（20–30 人），玩家無法自選房間
- **互動機制：碰撞與決鬥 (Engagement)**
	- 面對面碰撞或互動鍵 → 發起賭卡決鬥
	- 顯示押注稀有度但不顯示卡名
	- 雙方同意後切入對戰介面
- **撤離機制：出口的博弈 (Extraction)**
	- 安全出口：隨時離開結算
	- 貪婪出口：深處，額外獎勵但高風險
- **干擾元素 (Bomberman Style)**
	- 巡邏衛兵（NPC）：碰到即扣入場費並踢出
	- 寶箱與陷阱：提升探索與遭遇率
- **鏡像 NPC（Doppelgänger Bots）**
	- 生成外觀/牌組類似真實玩家的 AI
	- 玩家勝利獲得掉落（Faucet），失敗則資源回收（Sink）

積分機制:
