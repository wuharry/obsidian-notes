## 保存方式

```text
TRPG測試/
├── README.md                  場次索引
├── BUGS.md                    bug 權威總表與 Harvey 手動勾選
├── 判定原則與參考.md
├── 場次範本.md
├── 場次/
│   └── RUN-001-銀蹄酒館/
│       ├── 故事流程.md        保留收到的逐句內容
│       └── 結果與觀察.md      終局、觀察、重現與複驗
└── 參考資料/
    ├── 使用者提供的跑團示例.txt   逐字稿原文,正例出處
    ├── 擲骰時機與對照證據.md      判準 + 逐條 bug 的正例／反例
    └── 前次整理-LINE版進度.md     舊版整理,非現行
```

- 每次實測新增一個 RUN 編號；檔名不一定要有日期，日期未知就標未知。
- 故事、終局、原始 events 分開放進同一場次，沒有拿到的資料留待補，不代寫。
- bug 使用永久編號 B001…；重複問題補上新場次，不重開同義 bug。
- 自動測試通過不等於真人驗收。Harvey 在 `BUGS.md` 勾選確認後才視為關閉；復發保留歷史、取消勾選並追加證據。
