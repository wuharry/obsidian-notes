## 一、黃金原則:三個條件同時成立才擲骰

1. **結果不確定** —— 不是一定成功，也不是絕對不可能
2. **失敗有具體後果** —— 而且後果推進故事，不是單純卡住
3. **成功與失敗都有意義** —— 兩邊都值得敘述

任一條不成立就不要進 check 流程:

| 玩家宣告 | 擲骰？ | 原因 |
|---|---|---|
| 推開沒上鎖的門 | ❌ | 無風險、無不確定性，直接描述 |
| 對村民揮手打招呼 | ❌ | 日常動作 |
| 詢問公開資訊（誰發的委託） | ❌ | 資訊本身不設限，NPC 願意講就講 |
| 對已倒地的敵人補刀 | ❌ | 無風險，直接描述（本產品的失能規則仍由引擎處理） |
| 試著說服拒絕通行的守衛 | ✅ | 守衛可能生氣，有不確定性也有代價 |
| 偷看公爵的書信 | ✅ | 有被發現的代價 |
| 從 30 尺懸崖跳進水裡 | ✅ | 有受傷風險 |
| 跳上月球 | ❌ | 直接說不行，或只擲「失敗有多慘」 |

## 二、DM 三步驟公式

```text
1. DM 描述情境        → 給出可行動的資訊與鉤子
2. 玩家宣告行動        → 「我想做什麼」,不是「我成功了」
3. DM 裁定結果        → 自動成立／有意義的檢定／說明實際阻礙
```

**要說的是「你想怎麼做？」，不是「你成功了」或「你失敗了」。**

兩個常見反模式:

- **關鍵字判定** —— 判斷的是「有沒有可能失敗」，不是「玩家有沒有講對技能名或物件名」。
  玩家喊「我要擲說服喔！」是新手習慣，不該因此才給骰；反過來，玩家沒講技能名也不該拒絕行動。
- **等玩家自己找劇情** —— 玩家是被動反應的（reactive not proactive）。DM 要主動給「不去不行」的理由，
  但給了理由之後**玩家仍可探索或拒絕**，拒絕不等於放棄劇情。

## 三、逐字稿的擲骰全落在四類

把逐字稿裡每一次擲骰分類後，只有這四種:

| 類別 | 逐字稿實例 |
|---|---|
| **對抗檢定** | 洗牌作弊（手上功夫 vs 察覺）、擒抱掙脫（運動 vs 特技）、重排書架（手上功夫 vs 店主察覺） |
| **有隱藏層的察覺／洞察** | 環顧四周看誰在盯錢、看穿兜帽下不是半身人、判斷占卜是不是魔法、洞察對方有沒有說謊 |
| **有代價的技術行動** | 藏手弩入場、搜屍取財、書店找書（單次擲骰帶過整段） |
| **戰鬥** | 先攻之後的所有攻擊、豁免、法術攻擊 |

**零檢定的部分**（這是重點）:找座位、點餐、與女侍全部對話、詢問佈告欄內容、
問店主鎮上還有沒有別的書店、酒廠巡禮、絕大多數的桌邊社交。

> 這份分類可以直接當 **B004 白名單的依據** —— 不是列技能關鍵字，而是判斷行動落在哪一類。

## 四、逐條對照 bug

### B004 日常行動不該被強迫擲骰

**正例（逐字稿）**

- 連恩問「找位子坐很簡單嗎？」→ DM:「對，你走過去，坐下。」（全場笑）
  山姆接著吐槽「我們需要骰什麼檢定嗎？」—— 這個笑點本身就是判準:日常動作連問都不該問。
- 整段早餐、點餐、與女侍阿黛萊恩來回四五輪對話 → **零檢定**。
- 全場第一次擲骰是「我能環顧一下四周，看看有誰正盯著她數錢嗎？」→ 察覺。
  符合三條件:結果不確定、失敗代價明確（錢被盯上）、兩邊都有戲。

**反例（RUN-001）**

- T03 與老闆娘普通搭話 → 【失敗】總值 5 · 難度 12 → 行動被酒館噪音擋掉。
- T05 詢問公開委託人 → 【成功】總值 12 · 難度 12 → 資訊本身不設限，不該擲。

### B005 澄清只問一次，且承接前文

**正例（逐字稿）**

蘿拉:「你能幫我問問牌面，我能不能找到『他』嗎？」
塔利辛:「再多給我一點線索。你想找的這個『他』是誰？」
蘿拉:「我在找我爸爸。」
→ **問一次就推進**，立刻翻牌給出「眼」牌與解讀。

**反例（RUN-001 T05–T09）**

```text
玩家: 我接著問,我要去哪裡找鎮長？      ← 對象(守衛)+目的(找鎮長)都在句子裡
DM:  你想要詢問誰,酒保還是其他客人？    ← 丟失對象
玩家: 我想問剛剛那個守衛
DM:  你想要問剛剛的守衛什麼呢？        ← 丟失目的(上一輪已說「找鎮長」)
玩家: 有關鎮長的事
DM:  你想知道鎮長的什麼事？行蹤、住處…  ← 再細分一層
玩家: 住處
```

四輪反問才回答。**每一輪都把上一輪已給的資訊清空**，這是 context 沒有合併，不是玩家描述不明確。

### B008 保留玩家創意，由 NPC 立場決定成敗

**正例（逐字稿）**

- **創意被放大而非剝除**:蘿拉宣告要把書店書架全部重排、書背朝內、倒過來放 → 手上功夫自然 20 →
  DM 加碼:「你甚至在遠處角落像《魔鬼剋星》那樣把書一路從地板垂直疊到天花板，而店主完全沒有察覺！」
- **NPC 自主拒絕，但行動保留**:玩家想不交武器入場，連續三種說法（我們可以幫忙維安／免收入場費當副保鏢／你雇用我們）→
  雅莎「那是我的工作。所以不行」、半獸人波「規矩就是規矩」→ 但雅莎主動提折衷:「我可以整場都站在你們旁邊。」
  → 嘗試沒成功，但**沒有一句玩家的行動被改寫成別的行動**。
- **失敗有具體後果，意圖不被改寫**:山姆藏手弩 → 手上功夫 12 → 被雅莎當場抓到「不行、不行、不行，小女孩」→ 沒收。
- **敘事權交還玩家**:擊殺瞬間 DM 問「你要怎麼了結它？」（How do you want to do this?）→ 由玩家描述處決畫面。

**反例（RUN-001）**

朋友搭訕老闆娘的行動被 DM 轉譯改寫。應有的處理是:保留對象、方法、語氣、目的，
讓老闆娘依自己的立場接受或拒絕 —— **拒絕是 NPC 的選擇，不是把行動換掉**。

### B001 探索與拒絕委託都不等於放棄劇情

**正例（逐字稿）**

- 第一部（約半集）**零主線推進**:早餐、分錢、占卜、賭博出老千、拔短劍、逛三家酒廠、逛書店、重排書架。
  DM 全程沒有收束，也沒有催促。連恩甚至明說「我個人不太想現在就一頭栽進鎮上的紛擾中」，DM 直接接受。
- **節奏由玩家決定**:連恩「我能把逛書店找書簡化成單次擲骰嗎？」→ DM:「可以，就這麼辦。」
  瑪麗莎「只要用蒙太奇快速帶過啤酒巡禮」→ DM:「完全沒問題。」
  → 想快就蒙太奇帶過，**不是用結局把玩家收束掉**。
- **拒絕委託零懲罰**:佈告欄只剩滅鼠委託 → 山姆「聽起來超無聊的」→ 特拉維斯「還有別的委託嗎？」→
  DM 如實回答其他格子空著 → 玩家全部拒絕 → DM 直接推進到黃昏，沒有任何負面判定。

**反例（RUN-001）**

九個回合、其中五個是酒館內社交 → 進入遊蕩結局。

### B002 同義描述與狀態持續性

**正例（逐字稿）**

- 山姆:「牆上的佈告欄有貼什麼新委託嗎？」→ DM 直接回答內容，**沒有要求精確名稱**。
- **狀態持續**:佈告欄上「另一張紙大部分都被撕掉了」→ 連恩問「DM，那張是我撕掉的嗎？我有點記不清了」→
  DM:「沒錯，是你撕的。」→ 玩家先前撕告示的動作被記住並反映在描述裡。

**反例（RUN-001 T02）**

四份可見委託只輸出一份；且「告示」與「公告欄」被當成不同對象。

### B007 世界事實只能引用既有設定

**正例（逐字稿）**

- 連恩問鎮上還有沒有別的書店 → 店主席納指向**設定內既有地點**:「往北去札達許…深藍之魂圖書館」，
  並補上代價（「進入閱覽室代價不菲，除非你有學者通行證」）；接著明確認輸:
  **「如果你在我們這裡找不到想要的，我也幫不上忙了。」**
  → 不知道就說不知道，不憑空生一個本地地點。
- **DM 維護世界事實的權威**:玩家講錯學院名 → DM 當場糾正「是索崔斯（Soltryce）」；
  酒廠家族堅持要玩家報家族名而不是通稱「特羅斯特」。

**反例（RUN-001 T09）**

憑空給出鎮長住址「鎮上東邊、靠近市民廣場的那棟大樓」，並宣稱可以直接前往。
第一章未定義鎮長可互動地點。

> 順帶釐清:**「大樓」一詞不必然違反奇幻設定** —— 真正的缺口是「未設定的地點被宣布為可導航」。
> 把爭點放在用詞會抓錯方向。

## 五、參考來源

- **《Dungeon Master's Guide》** —— Ability Checks 與 The Role of Dice 章節。
- **D&D 2024 規則** —— 強調只有成功與失敗都有意義時才用 d20 Test。
- **Sly Flourish（The Lazy Dungeon Master）** —— Ability Check 相關文章:如何讓隨機結果有意義、何時該略過檢定。
- **Matt Colville《Running the Game》** —— 免費系列。玩家是被動反應的、DM 要主動給鉤子的論點出自此。
- **The Alexandrian《Three Clue Rule》** —— 每個必要結論準備至少三條線索。設計建議，非官方規則。
- 延伸搜尋詞:`when to call for a roll D&D`、`roll less D&D`。
- [使用者提供的跑團示例](使用者提供的跑團示例.txt) —— 本檔所有「正例」的出處。

## 六、不照搬的部分

- 逐字稿是**真人 DM 的即時判斷**，其中大量裁定依賴桌邊氣氛與玩家默契，不是可直接編碼的規則。
  本檔只抽出「哪些行動類別不進 check 流程」與「澄清該問幾次」這類可驗收的部分。
- 「倒地補刀自動命中」不作為本產品通則，攻擊與失能仍由引擎處理。
- 逐字稿的節目來源與集數未獨立核實。
