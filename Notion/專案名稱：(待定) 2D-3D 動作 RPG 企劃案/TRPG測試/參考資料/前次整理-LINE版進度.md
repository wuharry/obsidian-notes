# 前次整理：獨立 AI_TRPG LINE 版進度

> 此為前次查閱另一個 repo 的紀錄，不是本次 `/try` Web TRPG 的實作現況；兩者的地理、角色與規則不能混用。本次沒有重新核對 LINE 版。

## 狀態定義

| 狀態 | 意義 |
|---|---|
| 已實作 | 已有程式入口或可載入劇本內容；不代表所有模式均穩定 |
| 部分實作 | 只涵蓋限定劇本或部分流程 |
| 未實作／保留 | 原設計尚未落地，沒有視為已取消 |
| 待驗收 | 需要補足既定測試或真人體驗 |
| 待討論 | 需要確認是否納入目前 TRPG 方向 |

## 現行定位與已實作進度

- 玩家以繁體中文描述行動，AI 擔任 DM（主持故事與回應的說書人）；檢定、傷害、角色狀態及關鍵劇情階段由程式裁定。
- 目前是劇本式冒險，重點是調查、對話、戰術選擇與結局後果；不是即時操作的 2D／3D 動作遊戲。

## 現行角色與玩法文件

### 創角與檢定

| 項目 | 目前規則 |
|---|---|
| 屬性 | 力 `str`／敏 `dex`／智 `int`／魅 `cha`；不是原動作 RPG 六屬性 |
| 配點 | 合計 8 點，單項 0–4；礦坑以四位數輸入，例如 `4040` |
| 基礎 HP | 10 |
| 酒館技能 | 開鎖、洞察、威嚇、醫療、潛行、辯才，隨機取 2 項 |
| 礦坑冒險技能 | 洞察、潛行、威嚇、辯才中選擇，搭配職業能力 |
| 檢定公式 | `d20 + 屬性 + 適用且持有的技能加值 2 ≥ DC` |
| DC（成功門檻） | 6／8／12／16；依劇本與開團難度調整 |
| 成敗分級 | 大成功／成功／失敗／大失敗，由程式計算，不由敘事自行宣告 |

| 礦坑職業 | 起始武器 | 職業能力 |
|---|---|---|
| 劍士 | 長劍 | 易傷斬 |
| 盜賊 | 短劍 | 繞背突襲 |
| 牧師 | 法杖 | 醫療 |
| 弓箭手 | 長弓 | 腐蝕箭 |

```text
開團與組隊 → 選劇本／模式／難度 → 創角
→ 玩家描述行動 → 分類與合法性檢查 → 程式結算 → DM 敘事
→ 調查／對話／戰鬥／轉場 → 明確選擇與確認 → 結局
```

- 礦坑中受控守護者降至半血才暴露母礦；玩家明確取石後進入寄生核戰，不能單靠敘事或等待跳過戰鬥階段。
- 已有首領階段不等於原動作 RPG 的「削韌／霸體／打擊點」完成；它們是不同的操作規則。

## 已落地世界觀（企劃用，含劇透）

### 地理與共同舞台

```text
灰帆港
├─ 銅壺酒館 → 雨中後巷 → 碼頭舊倉庫（失竊案）
└─ 往內陸兩日 → 焦岩鎮 → 塌方側道 → 深淵石窟（礦坑救援）
```

| 設定 | 已寫入劇本的內容 | 邊界 |
|---|---|---|
| 灰帆港 | 有酒館、碼頭、商人、官府與走私活動的港鎮 | 尚無完整國家、年代史、世界地圖 |
| 焦岩鎮 | 位於灰帆港往內陸兩日，依賴礦山維生 | 與灰帆港的地理關係已明寫；沒有跨劇本旅途系統 |
| 星髓石 | 酒館案銀木盒中的違禁走私貨，牽涉失主隱瞞與木盒處置 | 不自行推定與熾心石、寄生核同源 |
| 燼喉 | 世代守護焦岩礦山、疏導地火的古龍；鎮民本來就知道牠存在 | 不是突然出現的邪惡巨龍，也不是寄生核本體 |
| 熾心石母礦 | 地熱調節核心、結構錨點與長期能源，關係礦坑能否安全開採 | 不是可隨時丟進背包的普通戰利品 |
| 熾心寄生核 | 沿地熱裂隙侵入母礦吸能，以根鬚控制燼喉的真正敵人 | 不是巴斯創造；與母礦、守護者分開記錄 |
| 巴斯 | 為產量與合約賄賂監工、拆封礦道、命人拆斷承重石樑 | 違規引發崩塌，提早暴露威脅；不等於他知道全部真相 |

### 劇本進度與核心抉擇

| 劇本 | 狀態 | 人數／設計時間 | 場景與主題 |
|---|---|---|---|
| 雨夜酒館的失竊案 | 已實作 | 2–4 人／約 30 分鐘 | 酒館問話 → 後巷追查 → 倉庫對峙；決定銀木盒的歸宿 |
| 焦岩礦坑的低吼 | 已實作／穩定性待驗收 | 1–4 人／約 150 分鐘 | 礦鎮調查 → 人質危機 → 守護者與寄生核；決定母礦與小鎮未來 |

> 人數與時間取自 YAML 的設計值，並非本次量測遊玩時間。

| 劇本 | 已定義結局 | 注意 |
|---|---|---|
| 酒館 | 遲來的正義、各取所需、共犯的十枚金幣、竊光者、沉入海底、竹籃打水、雨停之後 | YAML 共 7 個結局定義；不是所有項目都為主動選擇，也不能照舊 backlog 的五結局描述照抄 |
| 礦坑 | 守護者歸來、熾心的代價、碎心止災、沉默的交易、守護者殞落、晶災蔓延 | YAML 共 6 個；公共管理、占有、摧毀、利益交易與戰鬥失敗有不同條件 |

- 酒館 NPC 已有瑪爾塔、多爾克、芬恩、巴魯、皮普、連恩等具名角色與動機；不需要額外杜撰陣營去補齊原企劃。
- 礦坑 NPC 已有巴斯、老坎恩、葛蘿妲、鎮長梅芮、圖恩與燼喉。結局的代價涉及公共安全、生計與個人利益，不只有擊殺獎勵。
- 上述設定可作為未來 RPG 的世界觀素材；是否共用角色、時間線與玩家進度，仍需另外決定。

## 尚未完成／原動作 RPG 的去向

| 原設計或需求 | 狀態 | 與目前 TRPG 的關係 |
|---|---|---|
| 魔法三要素 INT／MND／DEX、物理 STR／END／TEC | 未移植／待討論 | 現行使用力敏智魅，不能將名稱相近視作相同規則 |
| 吟唱速攻／過載／反噬 | 未實作 | 未有按住施法、吟唱百分比與 MP 資源系統 |
| 動能／削韌／霸體／收招取消 | 未實作 | 即時動作規則保留；若改成 TRPG，需重新設計行動代價與判定 |
| 弱點切割／適正距離／彈道 | 未移植 | 劇本可有弱點與位置，不等於已有原企劃的物理模擬 |
| 六大基礎職業、進階轉職 | 未實作 | 礦坑已有四職；法師、遊吟詩人及整套轉職尚未落地 |
| 熟練度成長與動作解鎖 | 未實作 | 尚未建立長期角色養成與動作取消系統 |
| 自由金錢／購物／交易經濟 | 未實作 | 已有道具歸屬不代表有錢包與商店；礦坑劇本明說不追蹤採購 |
| 跨劇本角色／世界持續演變 | 未實作／待討論 | 地理相連，不代表酒館角色、道具、結局自動帶進礦坑 |
| 2D／3D 動作與原色碼 UI | 未實作於目前產品 | 目前為 LINE 文字／按鈕互動，保留原案視覺規範 |
| 新劇本與完整大世界 | 未完成 | 目前以兩個可載入劇本為基礎，其他國家、年代、陣營不自行補造 |
